## B. Limiti noti (non difetti)

| ID   | Limite                                                                                                                                                           | Impatto                                    | Mitigazione / quando                                                        |
| ---- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------ | --------------------------------------------------------------------------- |
| L-01 | **Nessun controllo di versione** nella modifica di una scheda: vince l'ultima scrittura (due schede aperte su dispositivi diversi si sovrascrivono)              | Basso (account singolo)                    | Si inviano solo i campi modificati. Token di versione se serve (M5)         |
| L-02 | Posizioni **duplicate** possibili dopo mosse concorrenti; l'ordine resta stabile per `id`                                                                        | Nullo per l'utente                         | Risolte al primo ribilanciamento ([kanban-ordering.md](kanban-ordering.md)) |
| L-03 | La bacheca carica **tutte** le schede attive in una richiesta (tetto 2000 con le archiviate)                                                                     | Prestazioni su bacheche enormi             | Tetto atomico; paginazione/virtualizzazione se necessario (M4)              |
| L-04 | **Peso del bundle** cresciuto: JS principale 293 → 452 kB (gzip 90 → 138 kB), per dnd-kit, Radix Dialog e il codice delle nuove viste                            | Primo caricamento più lento                | Caricare a richiesta la vista bacheca (code splitting) — M4                 |
| L-05 | Il trascinamento **da tastiera tra colonne diverse** non è stato provato (solo nella stessa colonna); il percorso tra colonne verificato è il menu "Sposta in"   | Accessibilità                              | Alternativa da menu garantita; prova manuale prevista in M4                 |
| L-06 | La **pressione prolungata** touch è provata con eventi touch reali di Chromium, non su iOS/Android; Firefox e WebKit non provati                                 | Compatibilità                              | Prova su dispositivi prima del rilascio privato (M4)                        |

| L-08 | I **preferiti** non sono ottimistici (attendono il server); la creazione di schede/colonne nemmeno (volutamente)                                                 | Cosmetico                                  | —                                                                           |
| L-09 | Autenticazione reale (Cloudflare Access), deploy e D1 remoto **non** provati (come in M0.H: limite ambientale 🔵)                                                | —                                          | Prima di M4 (deploy privato)                                                |
